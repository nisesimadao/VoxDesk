# VoxDesk

**マイクを鳴らしながら、オフボーカル音源を動画つきで再生する。**
歌詞つきの動画をそのまま映すので、画面を見ながら歌える。

Windows / macOS / Linux · MIT License

</div>

---

## これは何

家のパソコンをカラオケにするアプリ。

マイクの音を好きなスピーカーへ流しつつ、曲を探して伴奏を鳴らす。
伴奏もマイクも同じ出力先から出るので、イヤホン 1 本で完結する。

外部の再生ソフトも仮想ケーブルも要らない。Python のライブラリだけで動く。

## できること

- 曲名で検索して、**オフボーカルらしさを採点**して並べる（公式カラオケ配信元だけに絞ることもできる）
- **カラオケの人気ランキング**から選んで、そのまま検索できる
- YouTube の **URL を貼るだけ**でも再生できる
- 動画をそのまま表示するので、歌詞つきの動画ならそのまま歌える
- **時刻つきの歌詞**を自動で探して、映像の下に出す（外したら曲を指定し直せる）
- **キーを半音単位で変えられる**（曲まるごと作り直すので、継ぎ目のぷつぷつが出ない）
- 手持ちの音源ファイルも再生できる
- **スマホがリモコンになる**。同じ Wi-Fi でブラウザを開けば、曲の予約・キー・歌詞・映像が手元で使える
- 対応する GPU があれば、**どんな曲でも AI でボーカルだけ消せる**
- マイクの音作り（ノイズ除去・ゲート・コンプ・エコー）を内蔵。**ステレオのまま**通せる
- ノイズ除去は強さを選べるほか、**RNNoise**（AI）や、NVIDIA Broadcast / Krisp の仮想マイクにも切り替えられる
- 手持ちの **VST3 / Audio Unit** を挿せる。プラグイン本体の画面も開ける
- 入力と出力でサンプルレートが違っても繋がる（44.1kHz のマイク → 48kHz のスピーカー、など）
- 遅延と音の途切れ回数を画面に出す

## 動かすもの

| | 必要なもの |
|---|---|
| OS | Windows 10/11・macOS・Linux |
| マイク | 何でも。USB マイクやオーディオインターフェースが安定する |
| ボーカル除去（任意） | NVIDIA GPU（VRAM 4GB 以上）または Apple Silicon（メモリ 16GB 以上） |

## 入れる

[リリースページ](../../releases/latest)から落とす。

| OS | ファイル | 手順 |
|---|---|---|
| Windows | `*-windows-x64-setup.exe` | 実行するだけ |
| macOS (Apple Silicon) | `*-macos-arm64.dmg` | 開いて Applications へ入れる |
| Linux | `*-linux-x86_64.tar.gz` | 展開して `./VoxDesk` |

macOS は署名していないので、初回だけ右クリック →「開く」。
Linux は `sudo apt install libportaudio2` が要る。

**Intel Mac 向けは配布していない。**下の「自分で作る」で作れる。

## 動かす（ソースから）

```
git clone https://github.com/nisesimadao/VoxDesk.git
cd VoxDesk
```

Windows は `VoxDesk を起動.bat`、macOS / Linux は `chmod +x start.sh && ./start.sh`。
初回だけ準備に数分かかる。

## 自分で作る

配布物と同じものを手元で作れる。Intel Mac はこちら。

```
./build.sh          # macOS / Linux
.\build.ps1         # Windows
```

Python・tkinter・PortAudio の有無を確かめ、仮想環境を作り、
アイコンを生成して、`dist/` に一式を出す。
macOS なら dmg、Linux なら tar.gz、Windows は Inno Setup があればインストーラまで作る。
版を付けたいときは `./build.sh 1.2.0` のように渡す。

## 使う

1. **カラオケ**タブで曲名を入れて検索。★の多いものがオフボーカルらしい曲
   - 「ランキングから選ぶ」で人気曲から選んでもいい
   - YouTube の URL をそのまま貼ってもいい
2. 曲を選んで再生。スペースキーで再生と一時停止、左右キーで 5 秒送り
3. 高い・低いと感じたら **♭ / ♯** でキーを変える（作り直すので少し待つ。2 回目からは待たない）
4. **マイク**タブでマイクと出力先を選んで「マイクを入れる」

歌詞は自動で探して映像の下に出る。違う曲を掴んだら「曲を指定」で選び直せる。

> スピーカーから音を出すとマイクが拾って「キーン」と鳴る（ハウリング）。
> イヤホンかヘッドホンを使うのが確実。

うまくいかないときは**設定・診断**タブの「すべて調べる」。
使えるデバイス、音が来ていないデバイス、OS 側でミュートされているデバイスが一覧で出る。

## スマホをリモコンにする

パソコンの前に座っている人だけが操作できるのは、みんなで歌うときに不便。
**設定・診断**タブの「リモコンを使う」を入れると住所が出るので、
同じ Wi-Fi のスマホでそれを開く。

手元でできること:

- 曲を検索して**予約**（順番に流れる。曲が終われば自動で次へ）
- ランキングから選ぶ
- 再生・一時停止・次の曲・頭出し
- **キー**と**伴奏の音量**
- **歌詞**（今の行と次の行）
- **映像**

映像は、手元に取り込んだ曲ならスマホのブラウザが直接再生する（パソコン側の負担はほぼ無い）。
配信をそのまま鳴らしているときは、パソコンが描いている絵を送る。
音はパソコンのスピーカーから出るので、スマホ側は消音のまま合わせて動く。

> 開けている間は、同じ回線につながっている人なら誰でも操作できる。
> 既定では止めてあるので、使うときだけ入れる。

## マイクの音を作る

| プリセット | 想定 |
|---|---|
| カラオケマイク（有線・直挿し） | カラオケ用のマイクをパソコンのマイク端子に直挿し。足りない 20〜30 dB を補い、ハムとノイズを削る |
| USBマイク・ヘッドセット | いちばん安定する構成 |
| オーディオインターフェース | 機器側でゲインを取るので、アプリ側は控えめ |
| 加工しない | 素通し |

ノイズ除去は強さを選べる。NVIDIA Broadcast や Krisp を入れているなら、
「マイク側で処理」を選ぶとそちらの仮想マイクに切り替わる。

## ボーカルを消す

手持ちの曲や検索した曲から、AI（Demucs）がボーカルだけを取り除く。
YouTube の投稿者がカラオケ音源を上げているかどうかに左右されなくなる。

対応する機器があれば初回起動時に案内が出る。あとから**設定・診断**タブでも有効にできる。
約 3 GB を取得するが、アプリ本体には手を加えず、設定フォルダの中に入る。消すのもそこから。

作ったものは保存され、同じ曲を次に選んだときは待たずに再生される。
RTX 3090 で 4 分の曲がおよそ 20〜30 秒。

## 仕込み

| ファイル | 役割 |
|---|---|
| `router.py` | マイク → 出力の経路。入力と出力を別ストリームで開き、レート変換とドリフト補正で繋ぐ |
| `mic_chain.py` | 音作り。スペクトル減算のノイズ除去（numpy）と pedalboard のゲート/コンプ/エコー/VST3 |
| `player.py` | 動画再生。PyAV でデコードし、音声クロックに映像を合わせる |
| `separator.py` | Demucs でのボーカル除去。要件を満たす機器でのみ有効 |
| `model_installer.py` | ボーカル除去に必要なものを、あとから入れる |
| `music_search.py` | yt-dlp での検索とオフボーカル度の採点 |
| `pitch_render.py` | キー変更。曲まるごと変換してから鳴らす |
| `ranking.py` | カラオケの人気ランキングの取り込み |
| `lyrics.py` | 時刻つき歌詞の取得と、動画タイトルからの曲の推定 |
| `applog.py` | 記録。画面には短い日本語を出し、本当のエラーはファイルに残す |
| `devices.py` | デバイスの一覧と診断。実際に開いてデータが来るかまで確かめる |
| `platform_support.py` | OS ごとの違い（保存先・Host API・フォント・プラグイン探索先） |
| `vst_editor_host.py` | プラグイン画面を別プロセスで開く |

いくつか、はまりどころがあった。

**WASAPI はスレッドごとに COM 初期化が要る。** 忘れると `Unanticipated host error` としか出ず、
原因がまるで分からない。デバイスを開くワーカースレッドで初期化している（`comutil.py`）。

**プラグインの画面はメインスレッドからしか開けず、閉じるまで戻らない**
（[spotify/pedalboard#386](https://github.com/spotify/pedalboard/issues/386)）。
そのまま呼ぶとアプリ全体が固まるので、別プロセスに開かせて、つまみの値だけを送り返している。
同じ理由で報告されている「窓を動かせない」「複数開くと左上で重なる」も、
プロセス分離とウィンドウスタイルの付与で解消した。

**キー変更をブロックごとに処理すると無音になる。** pedalboard の PitchShift は
`reset=False` で小さく刻んで渡すと、出力が全て 0 になる（実測で 32768 サンプル以下は全滅）。
一括なら正しく動き、4 分の曲が 10 秒ほどで終わるので、曲まるごと作ってから鳴らしている。
継ぎ目が無いぶん、ぷつぷつや音の重なりも起きない。

**入力 44.1kHz・出力 48kHz は普通に起こる。** WASAPI 共有モードはデバイスごとにレートが固定
されるため、1 本のストリームでは開けない。別々に開いて間でリサンプルし、
バッファの溜まり具合を見てクロック差を吸収している。

## うまく動かないとき

1. **設定・診断 → すべて調べる**を実行する
2. `△ 開けるが音が来ない` と出たら、アプリではなく機器側の問題
   - 機器の入力切替（LINE / MIC）と録音レベルのつまみ
   - マイク本体のスイッチ、ケーブルの挿し込み
   - USB は別のポートに挿し直す
3. `ミュートされています` と出たらそこを解除する
4. Host API を変えると動く機器もある（Windows: WASAPI → MME）

音が途切れるときは、設定・診断タブのバッファを少しずつ大きくする（既定 25 ms）。

## 作る

タグを push すると GitHub Actions が各 OS 向けを作り、リリースに並べる。
手元で作るなら次のとおり。

```
pip install pyinstaller
pyinstaller --noconfirm --clean packaging/VoxDesk.spec
```

配布物に torch / demucs は含めていない（3 GB を超え、リリースは 1 ファイル 2 GB まで）。
